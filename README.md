# 🐦 Интерактивный каталог голосов птиц

Интерактивное веб-приложение на React + TypeScript + Vite + Tailwind CSS для прослушивания голосов и трелей птиц в живой природе.

## 🚀 Особенности

- 🎧 **Глобальная синхронизация звука**: воспроизведение одного трека автоматически останавливает предыдущий.
- 🎚️ **Кастомный плеер**: прогресс-бар, перемотка, отображение тайминга `ММ:СС`, кнопка беззвучного режима и сброса.
- 📸 **Карточки птиц**: фиксированные пропорции фото (`aspect-[4/3]`), анимация эквалайзера при воспроизведении, обработка ошибок изображений с fallback.
- 📱 **Полная адаптивность**: сетка на Tailwind CSS (`grid-cols-1 sm:grid-cols-2 lg:grid-cols-4`).
- 🕊️ **8 видов птиц**: Зяблик, Беркут, Орел, Фазан, Золотой фазан, Самка фазана, Зеленушка, Сорока.

## 📦 Установка и запуск

1. **Клонировать репозиторий**:
   ```bash
   git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
   cd <ИМЯ_ПАПКИ>
   ```

2. **Установить зависимости**:
   ```bash
   npm install
   ```

3. **Запустить локально (dev-режим)**:
   ```bash
   npm run dev
   ```

4. **Собрать для продакшена (деплой)**:
   ```bash
   npm run build
   ```

## 🌐 Деплой (Vercel / Netlify / GitHub Pages)

- **Vercel**: импортируйте репозиторий с GitHub, настройки сборки подхватятся автоматически (`npm run build`, папка `dist`).
- **Netlify**: Build command: `npm run build`, Publish directory: `dist`.
